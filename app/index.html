Internal Scripting

Command reference

`click "Calculator"`Tap the element whose text/desc contains "Calculator"
`type "hello world"`Type text into the focused field
`wait 1000`Pause 1000 ms
`repeat 3 { … }`Repeat the block n times
`if found "8" { … }`Run block only if text "8" is on screen
`else { … }`Else branch of the last if
`notify "Done"`Show a toast notification
`screenshot`Capture the current screen
`press back|home|recent`Press a system navigation key
`// comment`Line comment

Image / Template match

Tracker

Select a target to track it across app windows (highlight follows the element).

Detected elements glow on the phone screen. Click a detected element to inspect it.

Custom Keyboard

On-screen keyboard with microphone (voice) input. Works over the phone screen and any focused field.

Mic uses the browser Web Speech API; on a real Android device this maps to SpeechRecognizer.

Custom Clipboard

Persistent clipboard history with copy/paste across the phone simulator and form fields.

On Android this uses ClipboardManager with a foreground service so copied items survive app switches.
